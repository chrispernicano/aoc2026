    Language reference
    
      
      
      Top level
      
        
      sky from 1 to 100      -- or: to forever
planet p orbits 3 mass 0 { … }
moon m orbits 4        -- silent planet
eclipse p, q { … }     -- replaces both bodies
when quiet { … }       -- nothing rose
      
      
      Inside a body
      
        
      say "text {expr}"
launch moon orbits n
tug p to n             -- set p's orbit
drift by n             -- change own orbit
collapse               -- end the program
x if cond else y       -- last value = new mass
say "hi" if cond       -- guard any line
      
      
      Comets (input)
      
        
      comets                 -- number of input lines
comet                  -- this tick's line
digits of "L68"        -- 68
comet begins "L"       -- true or false
"11-22" after "-"      -- "22"
      
      
      Rules
      
        
      A planet rises on every tick its orbit divides. Bodies read every planet's mass from the previous tick. Dividing by zero makes a black hole that swallows the planet.
